What's new in Eraser 2.0

A few things changed with this version. Nothing needs doing, but they're worth knowing.

Countries

Your profile's country is stored as an ISO code. Brokers that only cover one market (a German credit bureau, say) are skipped if you're elsewhere, and the Brokers page says how many are hidden.

Encrypted passwords

Mail passwords are no longer stored as plain text. Settings has an optional passphrase for an extra gate; with one set, the OS schedule can't send, and delistd serve asks once at startup.

More in the web UI

Check bounces and Reclassify on the Pipeline page, and download all drafts as a zip from Brokers. Every one has a CLI twin.

Live settings, tidier config

Changes made in the CLI show up here without a restart. The old profile: block, email.provider and monitor --once are gone.
